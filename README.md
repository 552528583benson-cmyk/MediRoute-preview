# MediRoute 手機試用

香港醫療服務資訊 App 的課程原型，供組員在 Android 和 iPhone 上試用。可搜尋機構、按服務及地區篩選、查看詳情與地圖、收藏地點，並切換語言及主題。

**[開啟 MediRoute 試用版](https://552528583benson-cmyk.github.io/MediRoute-preview/)**

用手機掃描下方二維碼，或直接開啟上方連結：

![MediRoute 試用網址二維碼](mediroute-install-qr.png)

## Android 安裝

1. 用 **Chrome 的一般模式**開啟試用網址，保持連線完成首次載入。
2. 進入「**我的 → App 與更新 → 安裝 MediRoute**」，按畫面指示安裝。
3. 如果未出現安裝按鈕，開啟 Chrome 的「⋮」選單，選擇「安裝應用程式」或「加入主畫面」；部分版本會先顯示「安裝及建立捷徑」。
4. 回到手機主畫面，點 **MediRoute** 圖示開啟。

## iPhone 安裝

1. 用 **Safari** 開啟試用網址。如果在通訊 App 內開啟連結，先轉到 Safari。
2. 點「**分享 → 加入主畫面**」。部分 Safari 佈局需要先開啟頁面選單，再選「分享」。
3. 如有「作為網頁 App 開啟／打開為網頁 App」選項，保持開啟，再點「加入」。
4. 從手機主畫面的 **MediRoute** 圖示開啟。

如果分享選單沒有「加入主畫面」，可到選單底部的「編輯動作」加入此項目。選單文字可能因系統版本或語言而不同。

## 第一次試用

首次開啟可觀看或跳過教學；之後可在「我的」重新播放。

建議試一次：搜尋「北區醫院」→ 開啟詳情 → 複製地址／查看地圖 → 收藏 → 在收藏頁重新開啟。亦可試多選服務類型、切換地區、語言及主題。

## 版本與更新

- 版本號及「檢查更新」在「**我的 → App 與更新**」。
- 新版本準備好時，可選「立即更新」或「稍後」；更新會重新載入頁面。
- 收藏與設定儲存在目前瀏覽器／App；不同裝置不會自動同步。清除網站資料或移除 App 可能令本機紀錄遺失。
- 首次完整載入後，名冊、詳情和收藏可離線開啟；地圖底圖及外部網站需要網絡。系統可能回收離線快取。

## 回報試用問題

請在小組的原有溝通渠道附上：**App 版本、手機型號、瀏覽器、操作步驟及截圖**。請勿附上個人醫療資料。

這是使用公開資料的課程原型；機構資料請以相關官方來源為準。App 不提供診斷或醫療建議。

## 這個公開倉庫有甚麼用途？

這裡集中提供試用連結、安裝說明及已發布的網站檔案。GitHub Pages 使用這些檔案提供固定網址，讓組員試用及取得後續版本。

開發用的 React／TypeScript 原始專案、後端、資料庫及環境設定保存在私有專案。此公開倉庫只有網站建置檔、發布設定及試用文件；網站的 JavaScript、圖片及公開資料仍可被訪客下載和分析。

安裝方法參考：[Google Chrome 官方說明](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DAndroid&hl=en)、[Apple Safari 官方說明](https://support.apple.com/zh-tw/guide/iphone/iphea86e5236/27/ios/27)。
